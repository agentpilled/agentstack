## Notes on the voice

- Lowercase by default. Capitalize only proper nouns and the start of paragraphs (sometimes).
- Short sentences. Comma splices are fine; em dashes used sparingly and only where a comma would over-link.
- Disagrees politely but doesn't apologize for the cohort being expensive ("fair").
- Asks a question to keep the discovery going, but only one.
- Single emoji max, only when it actively replaces a word (🙏 = thanks back).
- Never says "definitely" / "absolutely" / "amazing" / "awesome".
